在真实场景中，使用完整应用和共享积压工作，探索 GitHub Copilot 在软件开发生命周期中的应用。你将通过迭代规划更改、编写代码、测试行为、审查 pull request，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为桌游众筹，并以开发者为主题。团队的积压工作已作为 GitHub issue 创建好，可以直接开始处理。其中既有筛选和分页等功能，也有无障碍和编码规范等质量改进。

## 选择开发环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择适合你的开发方式的环境。每场研讨会都有独立的设置流程，并使用同一个 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。体验 Plan 和 Autopilot 模式、说明文件、技能、自定义智能体、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中并行运行智能体会话、切换会话模式、协作处理 Canvas，并管理 GitHub issue 和 pull request。

### [GitHub Copilot 云智能体][cloud]

将 GitHub issue 分配给异步智能体，指导其工作、监控进度，并审查它创建的 pull request。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
