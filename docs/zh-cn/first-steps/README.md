入门体验研讨会通过引导式介绍，帮助你在没有现有应用或详细开发场景的情况下探索 GitHub Copilot。每场研讨会都从简单任务开始，在实际使用产品的过程中逐步介绍功能，并带你完成完整的工作流。

每场研讨会都会从空文件夹开始构建同一个 Space Quiz。你可以选择想学习的工具，也可以参加多场研讨会，比较不同工具的使用方式。

> [!NOTE]
> 这些研讨会由 [James Montemagno][james] 创建，并根据 [GitHub Copilot 入门体验][source-lab]改编。该项目采用 [MIT 许可证][source-license]。

## 研讨会

### [GitHub Copilot app 导览][copilot-app]

从空文件夹开始构建色彩丰富的 Space Quiz，并完成整个开发循环：创建、优化、测试、记录项目说明、发布、规划工作、实现 issue、审查并合并 pull request、自动执行重复工作，以及探索 Canvas 扩展。

### [GitHub Copilot CLI 入门][copilot-cli]

学习以终端为中心的工作流：在 Git 写入任何内容前构建项目并审查差异，在工作树中并行运行会话，先规划再编辑，管理上下文，然后不离开 shell 即可创建、合并和委派工作。

### [Visual Studio Code 入门][vscode]

学习以编辑器为中心的工作流：在工作区中构建项目，通过集成浏览器优化界面，检查上下文，在 Git 写入前运行测试，并使用 GitHub 工具处理 issue、pull request 和云会话，全程无需离开 VS Code。
