現実的なシナリオ、完成したアプリケーション、共有のバックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を活用します。変更を計画し、コードを作成し、動作をテストし、プルリクエストをレビューし、エージェントと作業を管理する反復型の開発を体験します。

## シナリオ

ボードゲームをテーマにしたクラウドファンディングを提供する架空の企業、Tailspin Toys の新しい開発者として作業します。チームのバックログは GitHub Issue として登録済みなので、すぐに取り組めます。機能追加としてフィルターやページネーション、品質改善としてアクセシビリティやコーディング標準などが含まれています。

## 環境を選ぶ

GitHub Copilot は普段の作業環境で利用できます。開発に使う環境を選んでください。各ワークショップでは個別にセットアップし、共通の Tailspin Toys シナリオに取り組みます。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを使います。Plan モードと Autopilot モード、指示、スキル、カスタム エージェント、Playwright MCP、Agent Merge、実用的なスラッシュ コマンドを活用します。

### [GitHub Copilot app][app]

デスクトップ アプリでエージェント セッションを並行して実行し、セッション モードを切り替え、Canvas で共同作業し、GitHub Issue とプルリクエストを管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub Issue を非同期エージェントに割り当て、作業をガイドし、進行状況を監視して、エージェントが作成したプルリクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。エディターを離れずに、Copilot Chat のエージェント モード、MCP サーバー、カスタム エージェントを活用します。
